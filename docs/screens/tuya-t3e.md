# 4-inch Tuya T3E Smart Panel

The **Tuya T3E Smart Panel** is a 4-inch square
touchscreen powered by **ESP32-S3**, with room for **9 cards**
on the home screen.

Community port contributed via [PR #660](https://github.com/jtenniswood/espcontrol/pull/660) by @txptr.

::: danger Currently broken
This device does not compile against the current pinned upstream version and has been pulled from the installer. Already-flashed panels keep working but will not receive updates until it is fixed.
:::

  setup:
