# Parity exceptions for guition-esp32-s3-jc8048w550
#
# Upstream v2.11.0 (jtenniswood/espcontrol) added an optional full-screen
# camera screensaver: common/device/screen_camera_screensaver.yaml (real
# feature) vs. common/device/screen_camera_screensaver_disabled.yaml (a
# no-op stub — same script/global IDs, empty bodies) for devices that don't
# support it. Every upstream reference device pulls in the real file with
# screensaver_camera_supported: "true".
#
# No community device has been verified against camera-screensaver hardware
# behavior yet, and the real file adds an artwork_image decoder plus an HA
# camera subscription that isn't free on these already flash/RAM-constrained
# boards. This device intentionally stays on the disabled stub
# (screensaver_camera_supported: "false") until someone verifies the real
# feature on hardware.
common/device/screen_camera_screensaver.yaml   # missing: disabled stub used instead, not verified on hardware
common/device/screen_camera_screensaver_disabled.yaml   # extra: intentional no-op stub for this device
